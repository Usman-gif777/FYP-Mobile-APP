# FYP Mobile (Expo SDK 54)

Cross-platform React Native app built with Expo SDK 54 and expo-router.

## Requirements
- Node.js 20+ (works with Node 22/24)
- npm 10+
- Expo Go app on Android 8+ or iOS 13+

## Run
```bash
npm install
npx expo start
```
Scan the QR code with the Expo Go app.

## Scripts
- `npm start` — start dev server
- `npm run android` — open on Android emulator
- `npm run ios` — open on iOS simulator (macOS)

## Stack
- expo ~54
- expo-router ~6
- react-native 0.81
- @expo/vector-icons (Ionicons)
- expo-linear-gradient
- react-native-safe-area-context, react-native-screens, react-native-gesture-handler

## Screens
Login → Signup → Dashboard → Assessments → Player → Voice → Reports
with bottom tab navigation across the main app screens.
